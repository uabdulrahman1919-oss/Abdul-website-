Selected academic and engineering projects

Final Year Project🔐

Design and Implementation of Generic High-Speed Multimodal Facial & Fingerprint Biometric Attendance System

Problem addressed: Improve attendance authentication by combining facial and fingerprint biometrics for stronger identity verification and efficient attendance recording.

Hardware / Technologies: Raspberry Pi 3, webcam, Mantra MFS100 fingerprint sensor, Arduino Nano, Python, biometric recognition, embedded systems.

Key outcome: Developed and tested a multimodal authentication approach using facial and fingerprint verification for attendance management.

Raspberry PiPythonFingerprintFacial Recognition
🚨

Design and Simulation of Microcontroller-Based Security Alarm System Using LDR

Problem addressed: Provide a simple electronic security solution capable of detecting changes in light conditions and triggering an alarm.

Hardware / Technologies: Microcontroller, Light Dependent Resistor (LDR), buzzer/alarm circuit, resistors, Proteus simulation and C programming.

Key outcome: Designed and simulated a functional LDR-based security alarm system for intrusion/event detection.

MicrocontrollerLDRProteusC/C++
💧

Simulation Smart Water Level Control System

Problem addressed: Reduce manual monitoring of water levels and support automatic control of water filling.

Hardware / Technologies: Microcontroller/Arduino, water-level sensing arrangement, pump/actuator, control logic and circuit simulation.

Key outcome: Designed a smart control concept that monitors water level and automatically manages the filling process based on defined conditions.

ArduinoSensorsAutomationControl
